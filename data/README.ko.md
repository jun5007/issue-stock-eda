# 데이터 공개 상태

이 디렉터리에는 문서만 있으며 원본·파생·합성·샘플 데이터는 포함하지 않습니다.

## 공개 파일

- `README.md`: 영어 데이터 공개 상태 문서
- `README.ko.md`: 한국어 데이터 공개 상태 문서

CSV, XLSX, HWP, Parquet, 데이터베이스, 샘플 데이터셋은 공개하지 않습니다.

## 권리 및 출처 제약

원본 팀 프로젝트는 저장소 README에 설명한 주식시장, 검색 트렌드, 뉴스량 데이터를 사용했습니다. 각 출처의 재배포 조건, 파생 테이블에 대한 권리, 팀 공개 동의는 공개 기록에서 확인되지 않았습니다.

따라서 다음 자료는 공개 대상에서 제외합니다.

- 원본 및 통합 데이터셋
- 파생 테이블과 분석용 데이터
- 팀 보고서와 발표 자료
- 복사한 그림
- 검증된 공개 스키마가 있는 것으로 오해할 수 있는 합성·샘플 대체 자료

저장소 README의 `3,620 × 29`는 원본 팀 문서에 남은 검증되지 않은 과거 기록이며, 이 디렉터리에서 제공하는 파일의 크기가 아닙니다.

## 재현성

현재 독립 재현은 불가능합니다. 이 문서는 검증된 스키마, 분석 기간, 값의 단위, 전처리 코드, Notebook, 실행 파이프라인, random seed를 제공하지 않습니다.

이 저장소에서 FOMO는 뉴스와 검색 활동을 바탕으로 한 시장 관심도의 대리변수만을 뜻합니다. 공개 데이터가 투자자의 심리나 행동을 직접 측정하지 않습니다.
