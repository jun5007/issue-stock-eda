# 데이터 접근 및 예상 스키마

상태: `SCHEMA_ONLY` · `NO_DATA_INCLUDED` · `LICENSE_REVIEW_REQUIRED`

이 디렉터리에는 문서만 있으며 원본·파생·합성·샘플 행은 포함하지 않습니다.

## 예상 로컬 입력

공개 Notebook은 `data/` 아래에 다음 로컬 전용 파일이 있다고 가정합니다.

### `주식통합.xlsx`

| 컬럼 또는 그룹 | 예상 자료형 | 용도 |
|---|---|---|
| `일자` | 날짜형 문자열 또는 datetime | pandas로 엄격하게 파싱해 `date`로 변환 |
| `종목` | 문자열 | 종목 식별자 |
| `종가`, `시가`, `고가`, `저가`, `대비`, `등락률` | 숫자 | 가격·수익률 항목 |
| `거래량`, `거래대금` | 숫자 | 거래 활동 |
| `시가총액`, `상장주식수`, `외국인 보유수량`, `외국인 지분율`, `외국인 한도수량`, `외국인 한도소진율` | 숫자 | 과거 전처리의 상태 항목 |
| `개인(매도)`, `개인(매수)`, `개인(순매수)` | 숫자 | 투자자 수급 항목 |

### `뉴스, 검색 데이터.xlsx`

| 컬럼 패턴 | 예상 자료형 | 용도 |
|---|---|---|
| `일자` | 날짜형 문자열 또는 datetime | 병합 키 |
| `검색량`을 포함하고 `_<종목>`으로 끝나는 종목별 컬럼 | 숫자 | 검색 관심도이며 접미사가 병합용 종목 키가 됨 |
| `NEWS 건수_` 또는 `건수_`로 시작하고 `_<종목>`으로 끝나는 종목별 컬럼 | 숫자 | 뉴스 건수이며 접미사가 병합용 종목 키가 됨 |

컬럼명과 자료형은 검토한 코드에서 추론한 예상값입니다. 공개 가능한 실제
데이터셋으로 검증한 스키마가 아닙니다.

## 로컬 파생 출력

Notebook은 다음 파일을 만들 수 있습니다.

```text
outputs/derived/이슈기준_통합데이터_final.csv
```

이 파일은 입력이 아니라 출력입니다. `outputs/`와 모든 CSV/XLSX 파일은
Git에서 무시하며 Commit하면 안 됩니다.

## 과거 통합 스키마 기록

원본 팀 문서에는 통합 데이터가 3,620행, 29개 변수였고 다음 항목이 포함됐다고
기록되어 있습니다.

`date`, `종목`, `검색량`, `뉴스건수`, `종가`, `등락률`, `거래량`,
`개인(순매수)`, `뉴스_log`, `검색_log`, `이슈강도`, `등락률_abs`,
`거래량_log`, `next_trade_date`, `등락률_next`,
`거래량_log_next`.

이는 검증되지 않은 과거 기록이며 공개 데이터셋이나 보장된 스키마가 아닙니다.

## 권리 및 출처 제약

프로젝트는 KRX 시장 데이터, 네이버 데이터랩 검색량, BIGKinds 뉴스량을
사용했습니다. 코드 공개 승인은 이러한 데이터나 파생 행의 재배포 권리를
의미하지 않습니다. 각 출처의 허용된 절차로 데이터를 확보하고 현재 이용조건을
별도로 검토해야 합니다.

복사한 뉴스 본문, 개별 기사 링크 모음, 팀 보고서, 발표자료는 포함하지 않습니다.

`이슈강도`는 시장 관심도의 간접적인 대리변수이며 투자자 심리나 FOMO를 직접
측정한 값이 아닙니다.
