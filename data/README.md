# Data Publication Status

This directory contains documentation only. It does not contain raw, derived, synthetic, or sample data.

## Public files

- `README.md`: English publication-status documentation
- `README.ko.md`: Korean publication-status documentation

No CSV, XLSX, HWP, Parquet, database, or sample dataset is published here.

## Rights and source constraints

The original team project used stock-market, search-trend, and news-volume data described in the repository README. The redistribution conditions for each source, the rights to derived tables, and team publication consent are not established in the public record.

For that reason, the following materials remain excluded:

- original and merged datasets,
- derived tables and analysis-ready files,
- team reports and presentation materials,
- copied figures, and
- synthetic or sampled replacements that could imply a verified public schema.

The `3,620 × 29` size mentioned in the repository README is an unverified historical record from the original team document. It does not describe a file available in this directory.

## Reproducibility

Independent reproduction is unavailable. This documentation does not provide a verified schema, analysis period, value units, preprocessing code, Notebook, executable pipeline, or random seed.

FOMO in this repository refers only to a market-attention proxy based on news and search activity. No published data directly measures investor psychology or behavior.
