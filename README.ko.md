# 뉴스·검색 트렌드와 주식시장 반응

> 시장 관심도 대리변수와 다음 거래일의 가격·거래량 반응에 대한 탐색적 분석
> 4인 팀 프로젝트 · 2025년 2학년 2학기

## 프로젝트 개요

뉴스 기사 수와 검색량의 변화가 다음 거래일의 주가 및 거래량 반응과 관련이 있는지 탐색한 프로젝트입니다. 뉴스 건수와 검색량을 결합한 `이슈강도`를 **시장 관심도의 해석적 대리변수**로 사용했습니다.

이 프로젝트에서 FOMO라는 표현은 투자자의 심리나 행동을 직접 관찰하거나 측정했다는 뜻이 아닙니다. 본 분석은 탐색적 분석이며, 인과관계를 입증하거나 매매 전략을 검증하기 위한 연구가 아닙니다.

## 연구 질문

뉴스량과 검색량이 증가한 날을 시장의 관심이 높아진 시점으로 보고 다음 세 가지 질문을 탐색했습니다.

1. 시장 관심도 증가는 다음 거래일 수익률의 방향과 관련이 있는가?
2. 시장 관심도 증가는 다음 거래일 거래량과 관련이 있는가?
3. 종목별 반응 패턴을 탐색적으로 군집화할 수 있는가?

원본 CSV, XLSX, HWP 파일과 팀 보고서는 데이터 이용 조건, 공동저작권, 팀 공개 동의가 확인되지 않아 공개하지 않습니다.

## 분석 방법

원본 팀 문서에는 다음과 같은 분석 절차가 기록되어 있습니다. 실행 코드와 데이터가 공개되지 않아 현재 저장소에서 독립적으로 검증된 절차는 아닙니다.

### 과거 데이터 처리 기록

1. 종목별 wide-format 데이터를 `date`, `종목`, `변수` 기준의 long format으로 변환
2. 뉴스·검색·시장 데이터를 `date`, `종목` 기준으로 결합
3. 휴장일에 발생한 이슈를 다음 거래일과 연결하기 위해 `next_trade_date` 생성
4. 가격 및 보유량 관련 항목을 forward fill
5. 거래량과 투자자 수급 관련 결측값을 분석 정의에 따라 0으로 처리
6. 뉴스 건수와 검색량에 `log1p` 변환 적용

| 변수 | 과거 문서의 정의 |
|---|---|
| `뉴스_log` | `log1p(뉴스건수)` |
| `검색_log` | `log1p(검색량)` |
| `이슈강도` | `뉴스_log + 검색_log` |
| `등락률_abs` | 일별 등락률의 절댓값 |
| `거래량_log` | `log1p(거래량)` |
| `등락률_next` | 다음 거래일 등락률 |
| `거래량_log_next` | 다음 거래일 로그 거래량 |

### 과거 분석 설계 기록

- **군집화:** 수익률 변동성과 거래량 spike 관련 요약값을 표준화한 뒤, 원본 팀 문서에 기록된 K-Means 설정 `K=3`을 적용
- **이벤트 비교:** 종목별 `이슈강도`가 가장 높은 날짜 하나를 이벤트일로 선정하고 전후 수익률과 거래량을 비교
- **휴장일 처리:** 휴장일의 이벤트를 다음 거래일 반응과 연결
- **상관관계 검토:** `이슈강도`와 다음 거래일 수익률·거래량의 관계 및 종목별 차이를 비교

이 방법들은 수업에서 학습한 기법을 제한된 탐색 데이터에 적용한 것입니다. 새로운 알고리즘이나 검증된 인과 모델을 제안한 것이 아닙니다.

## 과거 기록

다음 수치는 원본 팀 문서에 남아 있는 **검증되지 않은 과거 기록**입니다.

| 비교 | 과거 기록 | 현재 검증 상태 |
|---|---:|---|
| `이슈강도` vs. 다음 거래일 등락률 | 약 `0.03` | 재계산 및 독립 검증 불가 |
| `이슈강도` vs. 다음 거래일 거래량 | 약 `0.56` | 재계산 및 독립 검증 불가 |

원본 팀 문서에는 `K=3` 군집 중 하나에 에코프로만 포함됐다고 기록되어 있습니다. 이 singleton cluster 결과는 공개 저장소에서 검증할 수 없으며, 안정적인 시장 패턴으로 일반화해서는 안 됩니다.

이 관찰 결과는 제한된 과거 분석에서 나타난 연관성을 설명할 뿐입니다. 뉴스량이나 검색량이 이후의 가격·거래량 변화를 유발했다는 사실을 입증하지 않습니다.

## 한계

- 뉴스량과 검색량은 시장 관심도의 간접적인 대리변수이며, 투자자의 실제 FOMO·심리·행동을 직접 측정하지 않습니다.
- 긍정·부정 뉴스 방향을 구분하지 않아 관심 증가의 서로 다른 의미가 섞일 수 있습니다.
- 분석 표본은 10개 종목과 종목별 단일 대표 이벤트로 제한됩니다.
- 상관관계 분석은 종목·시장·시간 효과를 통제하지 않았으므로 인과관계로 해석해서는 안 됩니다.
- 과거 `K=3` 설정과 singleton cluster 기록은 공개 자료로 검증할 수 없습니다.
- 분석 코드, Notebook, 원본·파생·샘플 데이터는 공개되지 않았습니다.
- 과거 수치와 군집 결과는 현재 독립적으로 검증할 수 없습니다.

## 배운 점과 개선 방향

검색량과 뉴스량을 정리하고 시각화하는 과정에서 이러한 지표는 투자자 심리를 직접 측정하는 값보다 시장 관심도를 간접적으로 보여주는 값에 가깝다는 점을 배웠습니다.

또한 흥미로운 시각화가 인과적 결론을 정당화하지 않으며, 하나의 종목만 포함된 군집은 반복되는 시장 패턴으로 일반화하기에 불안정하다는 점을 확인했습니다.

향후에는 분석 기간과 군집 수를 바꿨을 때 관찰 결과가 유지되는지 검토할 계획입니다.
